# Входные данные

## Цель

Подготовить технический план динамического товарного фида для Яндекс Директа:

- товары берутся из фактического каталога Komui;
- любой товар, отображаемый на сайте, передаётся как `available="true"`;
- фид доступен по постоянной публичной HTTPS-ссылке;
- обновление выполняется автоматически, допустимая частота — раз в неделю;
- формат и поля соответствуют актуальным требованиям Яндекс Директа;
- перед планированием изучаются репозиторий, проектная документация и production-сервер.

## Ограничения текущего этапа

- Только исследование и планирование.
- Не изменять production-сервер, базу данных, DNS и рекламный кабинет.
- SSH использовать только для read-only диагностики; `sudo` — лишь для чтения системной конфигурации, если потребуется.
