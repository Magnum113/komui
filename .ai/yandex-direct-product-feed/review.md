# Review Yandex Direct feed

Дата последнего review: 2026-08-20.

## Этапы 1–4

- Блокирующих дефектов в генераторе, feed query, endpoint, nginx source config и тестах не обнаружено.
- Feed не зависит от public API limit и прекращает генерацию целиком при нарушении обязательных инвариантов.
- Availability соответствует решению владельца: все active products публикуются как available.
- XML escaping и фильтрация control chars покрыты тестом.
- Ограничения изображений покрыты тестами и проверены на production media.
- HTTP endpoint корректно различает успешный feed и ошибку исходных данных.
- Live-аудит подтвердил доступность всех текущих product pages и передаваемых изображений.

## Отложено по плану

- Production URL ещё не активирован: это выполняется атомарно вместе с backend deploy на этапе 5.
- Проверка валидатором внутри интерфейса Яндекс Директа возможна только после production deploy и относится к этапу 6.
- Постоянный server healthcheck добавляется на этапе 5 после появления публичного URL.
